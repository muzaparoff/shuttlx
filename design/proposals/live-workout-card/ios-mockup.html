Proposal 1 — Live Workout Card (iOS Dashboard)

Surface: ShuttlX/Views/Dashboard/LiveWorkoutCard.swift · Shown in Mixtape; Clean variant below

The problem, precisely. LiveWorkoutCard is the only hero surface in the app with no theme dispatch. It hardcodes cornerRadius: 16 (Mixtape's is 8), Color.yellow, Color.primary.opacity(0.06), and a Divider() (banned by design-system.md). Its background is an 8%-opacity accent tint, so the cassette-shell scene behind it — including two 96pt hub bezels pinned at y = 42% of screen height — shows through and collides with the control row. That is the "reels overlapping the buttons" in the screenshot. It is a bug, not a taste issue.

  • Opaque faceplate. Card fills with colors.background — the scene can never intrude. showHubs:false on scrolling screens.
  • J-card spine replaces the header. Same component as the full timer's jCardStrip — the card and the timer are now visibly the same object.
  • REC lamp is steady-lit, not pulsing. Real decks don't blink; kills a repeatForever loop.
  • LCD well + 52pt hero + ghost 88:88. The timer is unambiguously the loudest thing.
  • Pills → VU segment bar. HR reads pre-attentively as a level, not a number you must parse. Component already exists.
  • Transport keys. Reuses the existing ThemedTransportButtonStyle; PAUSE latches down while running — state is physical, not a label.
  • Felt-pad accent on the strip's leading edge, matching the timer hero exactly.

The skeleton is identical — spine → display well → metric strip → control row. Only the material changes. That is what makes this a pattern rather than a one-off: LiveWorkoutCard becomes a thin dispatcher, exactly like iPhoneWorkoutTimerView.

SlotCleanMixtape
SpineRing glyph + quiet uppercase captionCream J-card, SIDE A box, REC lamp
WellNo well — timer on glass, 54ptRecessed LCD, ghost 88:88, 52pt

If a retired theme is revived it fills the same four slots — e.g. Arcade: 7-segment spine → CRT well → pixel bar → chunky arcade buttons. No new mechanism.
